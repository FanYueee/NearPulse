NearPulse 近場脈動

語意座標取代經緯度的臨時情報迴路 — 3 秒零打字回報 · 1-Tap 群眾驗證 · AI 微任務指派 · 事實保鮮期
開始通報 (手機) 進入後台 (電腦)

核心創新 與既有方案結構性不同的四個機制

語意座標定位 獨家

想像你身在巴黎地鐵 B2 的角落：GPS 全死、指標全是法文、你連站名都說不出。NearPulse 不猜位置——你把眼睛看到的大字告訴系統：月台門號九宮格點一下；看不懂選項？直接輸入「SORTIE 3」這幾個字，人眼就是 OCR。機場看登機門（B12）、百貨看專櫃招牌（ZARA 3F）——這些是各國法規強制存在、眼睛一定找得到的錨點。每一步都可以跳過，全部跳過照樣能通報。

效益 — 零權限、零硬體、跨語言，在 GPS 死亡地帶完成連地圖都做不到的定位

地標式引導 創新

沒有經緯度，方向引導靠什麼？靠眼睛找得到的東西：「找綠色緊急出口燈箱（黑暗中發光），沿箭頭疏散」「你在地下層——優先找往上的動線」。引導引擎依空間類型（月台/走道/登機門/百貨）與樓層生成，摘錄進 Catch-up 卡，異國旅客不必讀懂地圖也能行動。

效益 — 從「你在哪」到「你該往哪走」的閉環，不依賴任何定位技術

1-Tap 群眾驗證 獨家

第一人回報後，周遭群眾不需要進群打字，一顆按鈕完成「我看到了 / 沒看到」投票。信心分數公式完全透明：基礎 20 分，每確認 +12（上限 60），每未見 -15，隨時間衰減。惡作劇會被 15 個「沒看到」壓制。

效益 — 把 Waze 的行車回報置信度衰減，移植到步行逃生

AI 微任務指派 創新

旁觀者效應：現場人越多，越沒人回報。AI 指揮官不對空氣喊話，隨機指名一位在場成員「@你：請回報傷患狀況」，30 秒未回應才升級全員。回應即記錄，寫進落幕報告與演習評分。

效益 — 把「有人會處理吧」變成「就是我來處理」

完整功能 從第一目擊到落幕歸檔的閉環

事件臨時群組 核心

掃 QR 或輸入 4 位代碼免安裝加入（PWA），事件落幕自動解散、30 分鐘後清除，不留永久雜訊。

效益 — 對比 Citizen 的永久恐懼推播，用完即散

零打字狀態機回報 核心

7 大類 × 細項 + 4 級嚴重度全點選，恐慌下 3 秒完成；也支援語音輸入（AI 即時轉文字並代填表單）。

效益 — 符合戰逃反應下的操作極限

AI 指揮官 + 追問

主動追問缺失的位置／傷患／威脅，事實面板附完整度進度條，45 秒週期追蹤。

效益 — 混亂現場自動收斂結構化情報

Catch-up 摘要卡

晚加入者 10 秒看懂全貌：事件、位置、傷患、威脅、導流指引，不必爬數百則訊息。

效益 — 每個新進者都是即戰力

闢謠引擎

新回報與已知事實矛盾時自動標記「未經證實」並附原文；結合 1-Tap 投票形成雙層防線。

效益 — 假訊息跑得比查核快，就被演算法追上

照片邊緣運算 創新

前端 Canvas 壓縮（800px WebP <30KB）＋ Laplacian 變異數模糊篩檢，廢片（黑屏/手指/全糊）在端點攔截，不佔基地台頻寬。

效益 — 基地台塞車時每筆上傳都是高價值訊號

分區導流

點選風險分區即全員廣播「避開 B 區」，疏散不靠喊的。

效益 — 人潮有序撤離

多語語音播報

一鍵中→英→日輪播事件簡報，聽覺無障礙。

效益 — 外籍人士與視障者即時掌握

落幕報告書

時間軸、參與統計、矛盾數、信心分級事實，自動生成、SQLite 歸檔可查。

效益 — 事件留下可檢討的紀錄，救災交接不斷層

演習模式 + AI 評分

學校/企業日常演練：機器人注入模擬民眾雜訊與矛盾訊息，AI 對五項目標評分（指派回應/事實補齊/多模態/導流/落幕）。

效益 — 把冷啟動問題變成日常演練習慣

電腦後台指揮中心

桌面瀏覽器自動進入：事件總覽、即時監控（observer 旁聽不干擾現場）、信心分數儀表、分區導流、落幕、統計、手機即時預覽。

效益 — 站務/校方一屏掌控大局

雙模式通報

GPS 可用時自動定位＋地址反查；進入地下即切語意座標。兩種模式進入同一資訊迴路。

效益 — 定位是加速器，不是門檻

與既有方案的差異 結構性做不到，不是功能差距

異國模擬情境 後台一鍵注入，手機＋電腦同屏共演

  1. 巴黎地鐵：GPS 失效 + 多語群眾——「Je ne comprends pas…」與中文回報混雜，AI 照樣收斂出「月台門 3 有傷患」，引導卡指示「找往上動線」
  2. 機場登機門 B12：複雜樓層 + 醫療情境——旅客昏倒、地勤回報 AED 位置、家屬更新意識狀態
  3. 百貨 3F 走失：低嚴重度日常情境——店員安撫、顧客引導服務台、媽媽趕到，完整走完溫柔版本的生命週期
  4. 後台「重置 Demo」按鈕：事件與統計全部歸零，任何時刻回到乾淨起始狀態，開箱即演

3 分鐘演示腳本 評審 Demo 可直接照做

  1. 電腦開後台（桌面瀏覽器開首頁自動進入 /console）— 左欄事件列表、右欄手機預覽同屏
  2. 手機 A 通報：開 /mobile/ → 選「傷病」→「月台」→ 點「3」（月台門）→ B2 →「緊急」→ 建立；注意通報過程完全沒打字
  3. 後台即時看到事件出現，AI 指揮官自動追問缺失事實，事實面板從 33% 開始爬升
  4. 手機 B 加入：輸入 4 位代碼（或掃後台顯示的 QR）→ 收到 10 秒 Catch-up 摘要卡
  5. 1-Tap 驗證：手機 B 對事件按「我看到了」→ 後台信心分數即時 +12；再按「沒看到」模擬反向信號 → 分數下降
  6. AI 微任務：AI 指名 @某人 回報 → 被指者的任何訊息即為回應，後台看到指派卡與回應紀錄
  7. 闢謠：回報 popover → 示範照片「已無煙」→ 闢謠引擎標記矛盾「未經證實」
  8. 真實照片：拍照回報 — 前端顯示「已送出 xxKB（邊緣篩檢通過）」，模糊/過暗照片會被當場攔截
  9. 導流：後台點分區 → 手機全員收到「避開 B 區」廣播
  10. 落幕：後台一鍵落幕 → 報告書生成（統計/時間軸/矛盾數）→ 群組自動解散
  11. 演習：手機首頁啟動「學校火警」→ 機器人注入雜訊 → 完成五目標 → AI 評分 100/優

誠實揭露：WebSocket 群聊 / QR / GPS 反查 / PWA / 語音辨識 / 共識投票 / SQLite / 邊緣壓縮為真實運作； 照片內容解析與 LLM 判讀為可切換介面（填入 API Key 即用真模型，未設定時規則引擎降級）。 氣壓計樓層 / Wi-Fi BSSID / 聲波浮水印列為 Roadmap——它們在純 Web 環境會現場翻車，我們不做會翻車的功能。
